JAVA LAB PROGRAMS (1 TO 10)
===========================

Included Files:
1. Program01_JavaConstructs.java     - Exercises in Java Programming Constructs
2. Program02_OOPSConcepts.java       - Program to implement OOPS concepts
3. Program03_MethodOverloading.java  - Method Overloading
4. Program04_ExceptionHandling.java  - Exception Handling (try, catch, finally)
5. Program05_CustomException.java    - User-Defined / Custom Exception Subclass
6. Program06_Multithreading.java     - Multithreading using Thread class
7. Program07_MultipleInheritance.java- Multiple Inheritance using Interfaces
8. Program08_GenericStack.java       - Generic Classes (Stack Operations)
9. Program09_SwingCalculator.java    - Basic Calculator (Sum of Two Numbers) using Java Swing
10. Program10_AppletSum.java         - Java Applet to display the Sum of Two Numbers

How to Compile and Run (Programs 1 to 9):
-----------------------------------------
javac Program01_JavaConstructs.java
java Program01_JavaConstructs

(Repeat similarly for Programs 02 through 09)

How to Compile and Run Program 10 (Applet):
-------------------------------------------
Note: Applets require JDK 8 (or an JDK version that includes appletviewer).
javac Program10_AppletSum.java
appletviewer Program10_AppletSum.java
